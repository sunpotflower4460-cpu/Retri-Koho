# Retri-Koho — 『Re:trip』広報本部

「Re:trip」（fra）の日々の広報活動・数字・機会・文面を積み重ね、前進し続けるための場所。

## 運用ルール

- 送信・提出・支払いはユーザー本人のみ行う。Muse は準備と記録を担う。
- 楽曲クレジットは厳密に守る: **作詞・作曲: 植木嘉朗（fra）／レコーディング以降は別の担当者**。本人が録音・ミックスまでしたと書かない。
- 架空の実績（再生数・掲載・受賞など）を書かない。数字は確認できたものだけを記録する。
- 個人情報（住所・電話番号など）はこのリポジトリに置かない。

## ファイル構成

- [song/fact-sheet.md](song/fact-sheet.md) — 曲の確定情報（クレジット・配信先・使ってよい表現）
- [log/2026-11.md](log/2026-11.md) — 広報活動の日次ログ
- [metrics/metrics.csv](metrics/metrics.csv) — 公開数字の推移
- [opportunities/backlog.md](opportunities/backlog.md) — 広報機会のバックログ
- [templates/pitches.md](templates/pitches.md) — ピッチ文テンプレート
- [content/ideas.md](content/ideas.md) — コンテンツの種リスト
