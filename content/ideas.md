# コンテンツの種リスト

投稿・動画のネタを積む場所。使った種には実施日と反応メモを残し、当たった型を増やす。

| 種 | 実施日 | 反応メモ |
|---|---|---|
| リリック動画のサビ部分を切り出したリール（フルの誘導つき） |  |  |
| 歌詞の一節を取り上げて、その言葉に込めた世界観の話をする投稿 |  |  |
| 作詞・作曲の制作背景を語る投稿（曲が生まれたきっかけや言葉選び） |  |  |
| 「再訪の景色」Shorts／リール: MVの自然・風景カットを使い、冒頭3秒で概要欄の一文「同じ場所に来ても、あなたと来ると違って見える」を大きく表示→サビへ。締めは「あなたの『もう一度行きたい場所』はどこですか？」。Instagram版はプロフィールリンクへ誘導、YouTube Shorts版は説明欄URLが押せないため関連動画にフルMVを設定（案: 2026-11-11 Muse） |  |  |
