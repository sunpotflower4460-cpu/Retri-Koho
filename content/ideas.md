# コンテンツの種リスト

投稿・動画のネタを積む場所。使った種には実施日と反応メモを残し、当たった型を増やす。

| 種 | 実施日 | 反応メモ |
|---|---|---|
| リリック動画のサビ部分を切り出したリール（フルの誘導つき） |  |  |
| 歌詞の一節を取り上げて、その言葉に込めた世界観の話をする投稿 |  |  |
| 作詞・作曲の制作背景を語る投稿（曲が生まれたきっかけや言葉選び） |  |  |
| 「再訪の景色」Shorts／リール: MVの自然・風景カットを使い、冒頭3秒で概要欄の一文「同じ場所に来ても、あなたと来ると違って見える」を大きく表示→サビへ。締めは「あなたの『もう一度行きたい場所』はどこですか？」。Instagram版はプロフィールリンクへ誘導、YouTube Shorts版は説明欄URLが押せないため関連動画にフルMVを設定（案: 2026-11-11 Muse） |  |  |
| 「曲名の意味から入る15秒」Shorts／リール: 冒頭3秒は黒背景に大きな文字「Re:trip の Re は『もう一度』」→ MVの風景カットに切り替え、文字で「同じ場所への、2度目の旅の歌」と補足 → 締めは「フルはプロフィール／関連動画から」。素材は既存MVの風景部分のみ（歌詞字幕は使わない）。キャプション案: 「曲名に込めた『もう一度』。同じ場所でも、誰と行くかで景色は変わる。あなたの『もう一度行きたい場所』はどこですか？ #Retrip #fra #オリジナル曲」（案: 2026-11-12 Muse、今朝のリリック切り出しリールとは別内容） |  |  |

| 「光の移り変わり15秒」Shorts／リール: 冒頭3秒で MV の暗めのカット→明るい風景カットへ切り替え、大きな文字「同じ場所、違う景色」→ サビの光のカットへ。締めは「フルはプロフィール／関連動画から」。素材は既存MVの風景カットのみ（歌詞字幕は使わない）。キャプション案: 「同じ場所でも、光と、誰と来るかで景色は変わる。fra『Re:trip』フルはプロフィールから #Retrip #fra #オリジナル曲」（案: 2026-11-13 Muse、金曜のショート動画重点。今朝の別ジョブとは別内容） |  |  |

| 「冒頭のギターで始まる15秒」Shorts／リール: 冒頭3秒は MV 冒頭のギターの入りをそのまま使い、大きな文字「最初の数秒で、旅が始まる」→ サビの風景カットへ。締めは「フルはプロフィール／関連動画から」。素材は既存MVのみ（歌詞字幕は使わない）。キャプション案: 「始まりはギターと歌。同じ場所でも、誰と来るかで景色は変わる。fra『Re:trip』フルはプロフィールから #Retrip #fra #オリジナル曲」（案: 2026-11-14 Muse、土曜の種。今朝の別ジョブとは別内容） |  |  |

※ 試作の歌詞字幕は自動聞き取りによるサビ部分のみで、正式な歌詞として扱わない。
