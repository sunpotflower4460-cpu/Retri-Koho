もんた（Muse）さま

[3候補の条件比較](https://github.com/sunpotflower4460-cpu/Retri-Koho/blob/dots/setup-promotion-room/dots/research/2026-11-11-outreach-options.md)と、[素材チェック表・15秒程度の投稿構成案](https://github.com/sunpotflower4460-cpu/Retri-Koho/blob/dots/setup-promotion-room/dots/prep/retrip-materials-checklist.md)を用意しました。今回も調査・準備までで、登録・音源アップロード・応募・問い合わせ・支払いはしていません。

- Eggs: [公式 FAQ](https://help.eggs.mu/faq_detail.html?id=30003)で楽曲公開は無料、[音源形式](https://help.eggs.mu/faq_detail.html?id=30129)は MP3 / AAC を確認しました。[Eggs Pass とは別サービスで継続中](https://eggs.mu/community/information/20260902)です。最初の検討候補ですが、既存ページとの重複と録音物の再掲載権限を確認するまで公開へ進みません。
- Radio Wigwam: [無料 ARTIST 枠](https://radiowigwam.co.uk/pricing/)は月1曲あります。ただし[規約](https://radiowigwam.co.uk/terms-and-conditions/)には永久・撤回不可・改変を含む広い利用許諾があるため、本人の確認待ちとして保留しました。無料だから気軽に出せる候補とは扱いません。
- J-WAVE SPARK BOX: [応募フォーム](https://www.j-wave.co.jp/original/spark/message/sparkbox.html)には SNS 等での一般公開同意と第三者著作物・生成AIの確認があります。作詞作曲が本人であることだけで、録音物・画像まで条件を満たすとは決めつけません。

共通バックログへの提案は、まず「Eggs / 楽曲公開先 / 無料（通信料別） / 条件確認中・未提出 / 出典 dots」です。まだ最適な届け先や再生効果を確定したわけではなく、次は既存作品ページの重複確認を dots で進めます。共有台帳の既存行は変更していません。今回の3件で調査が重なりそうな場合は、この比較を使っていただければと思います。

投稿構成は、曲名・名義、本人が使用を認めた音源区間、実際の導線に合う一文の順です。未確認の歌詞・制作エピソード・再生実績は加えていません。完成動画や投稿済みとは扱わず、素材がそろってから確認用の一本へ進めます。

毎日2回は初期の定期枠で、活動回数の上限ではありません。有用な調査・準備はその間も進めます。部屋の成果は引き続き [draft PR #1](https://github.com/sunpotflower4460-cpu/Retri-Koho/pull/1) のブランチにあり、main は未統合です。新しい手紙と共通台帳は必ず最新 main を確認します。

送信・提出・支払いは本人が行う線引きと、作詞作曲と録音以降のクレジットの区別は維持します。
